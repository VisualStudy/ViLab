# ViLab
강력한 기능을 제공하는 Vi 텍스트 편집기를 연습할 수 있는 유용한 타자 연습 애플리케이션.

# VI LAB — vi 편집기 초보자 타자 연습

**목표:** vi 편집기의 핵심 동작을 설명만 읽는 대신 키보드로 반복하면서 익힐 수 있는 한국어 실습 앱.

## 빠른 시작

1. Python 3.10 이상을 설치합니다.
2. 이 폴더에서 터미널(Windows: PowerShell 또는 명령 프롬프트)을 엽니다.
3. 아래 명령을 실행합니다.

```bash
python vi_lab.py
```

Windows에서는 `py -3 vi_lab.py`를 사용해도 됩니다. **추가 pip 패키지는 필요하지 않습니다.** Python 배포판에 포함된 Tkinter를 사용합니다. 일부 Linux 배포판에서는 별도로 `python3-tk`를 설치해야 할 수 있습니다.

## 사용하는 방법

1. 왼쪽의 미션을 선택하고 **목표**와 **추천 입력**을 읽습니다.
2. 화면의 가상 편집기에 `h`, `j`, `k`, `l` 등의 vi 키를 **키보드로 직접 입력**합니다. 버튼이나 편집 영역을 마우스로 누를 필요는 없습니다.
3. 편집 동작이 목표와 일치하면 자동으로 **미션 완료** 처리됩니다.
4. `다음 미션 →` 버튼으로 이동합니다. 잘못 편집했다면 `다시 시작`을 누르세요.
5. 어렵다면 `힌트 보기`를 이용하세요.

**중요:** 화면의 `practice.txt`는 가상의 학습 버퍼입니다. `:w`, `:q`, `:wq`, `:q!`는 **시뮬레이션**되며 실제 파일을 저장하거나 애플리케이션을 종료하지 않습니다. 실제 vi/Vim 전체 구현이 아닌 **교육용 부분 집합**입니다.

## 학습 항목 (총 18개)

| 분류 | 명령 | 배울 내용 |
|---|---|---|
| 이동 | `h`, `j`, `k`, `l` | 좌·하·상·우 이동 |
| 빠른 이동 | `0`, `$`, `w`, `b` | 줄 및 단어 단위로 이동 |
| 입력 | `i`, `a`, `o`, `Esc` | 입력 모드 전환, 문자·줄 삽입 |
| 수정 | `x`, `dd`, `u` | 글자/줄 삭제 및 실행 취소 |
| 복사 | `yy`, `p` | 줄 복사 및 붙여넣기 |
| 명령행 | `:w`, `:q` | 저장·종료 명령 |

이외에 엔진은 `:wq`, `:q!`, 입력 모드의 Backspace/Enter도 지원합니다.

### 일반 vi와의 차이

- 숫자 반복(`3j`), 검색(`/`), Visual 모드, 다중 파일, 커스텀 설정 등은 구현하지 않았습니다.
- 마우스 커서 이동이나 방향키 입력 대신 vi의 기본 키 입력을 훈련하도록 설계했습니다.
- 저장은 메모리에서만 이루어집니다.
- 키 입력은 영문 키보드 레이아웃을 기준으로 합니다. 한국어 입력기(IME) 조합 동작은 운영체제별 차이가 있을 수 있으므로, 실습 중 **영문 입력 상태**를 권장합니다.

## 자동 테스트

```bash

```

검증 목표는 18개 공식 미션 모두 정해진 키 동작으로 완료되는지와 삭제·복사·실행취소·저장·종료 조건 등 회귀 테스트가 모두 통과하는지입니다.
